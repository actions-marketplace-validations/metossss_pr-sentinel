# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within **PR-Sentinel**, please do **NOT** open a public issue.
Instead, follow responsible disclosure:

1. Send an email to the repository maintainers or use GitHub's private vulnerability reporting feature.
2. Include a detailed description of the vulnerability, steps to reproduce, and impact.
3. We will acknowledge receipt within 48 hours and work with you to patch and disclose the issue responsibly.
